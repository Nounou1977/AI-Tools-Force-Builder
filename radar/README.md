# Radar demandes chaudes

Veille automatisée des nouveaux signaux publics.

- Exécution planifiée toutes les 5 minutes via GitHub Actions (best effort).
- Sources initiales : flux RSS publics Google News.
- Aucun contournement de connexion, CAPTCHA ou protection.
- Déduplication locale et score heuristique.
- Une issue GitHub est créée uniquement pour les signaux >= 85.
- Les propositions restent à valider humainement avant tout contact ou publication.
